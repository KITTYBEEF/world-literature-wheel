# 🌍 世界文学大转盘 · World Literature Wheel

**让随机性带你遇见陌生的文学世界。**

一个随机探索世界文学的网站。

依次抽取时代  → 国家 → 作家性别 → 文学文体，最后随机得到一本符合条件的书。

我不太相信“完美的推荐”。

与其让算法不断告诉我们“你可能喜欢什么”，不如偶尔把选择权交给随机性，去遇见一本原本不会出现在你眼前的书。

在线体验：

<https://literaturewheel.com>

---

🎲 玩法

1. 抽取一个时代
2. 选择大洲范围
3. 地球自转，随机抽取一个国家
4. 抽取作家性别
5. 翻书抽取文学文体
6. 查看最终推荐的书目
7. 如果感兴趣，就去寻找它、阅读它

整个过程不是为了找到“最适合你的书”，而是为了让你遇见原本不会主动选择的书。

---

✨ 特性

- 🌍 8 个文学历史时代
- 🗺️ 覆盖全球多个国家与地区
  - 不同时代对应不同的国家与地区范围
- 📚 世界文学书库
  - 收录来自不同国家、时代和文化背景的文学作品
- 🌐 中英双语界面
- 🎲 完整抽签流程
  - 时代 → 大洲 → 国家 → 性别 → 文体
- 📜 抽签历史记录
  - 使用浏览器本地存储保存个人历史
- 👩‍💻 伪 Live2D 看板娘 + Q 版桌宠
- 🃏 分享卡片生成
  - 可以把自己的抽签结果分享出去

注：时代、国家与地区的划分并非绝对，较为模糊。分类更多依据于文化和地域背景。

💡 为什么做它？

有一天我突然想：

如果把世界上每个国家的文学都轮着读一遍，会是什么样？

然后我开始查世界上有哪些国家。

太多了！！！

再想到人类已经有几千年的文明历史——那么以前的作品呢？

更多了！！！！！！

面对这么多书，我不知道应该从哪里开始......

所以我想：

**如果我不选择呢？**

**如果让随机性替我选择呢？**

于是有了世界文学大转盘。

它不是传统意义上的“推荐系统”。

我希望它能够带人去一个没有去过的地方，看一本没有看过的书，认识一些原本不会遇见的人和思想。

也希望我们偶尔能够离开算法为我们准备好的信息，走一条不那么相似的阅读路径。

🛠️ 技术

本项目为纯前端项目，无后端。

主要使用：

- HTML
- CSS
- JavaScript
- "D3.js" (<https://d3js.org/>)
- TopoJSON
- Canvas
- "localStorage"

主要实现

- 使用 D3.js + TopoJSON 绘制与控制地球
- 使用 Canvas 生成分享卡片
- 使用 localStorage 保存用户偏好与抽签历史
- 前端完成随机抽取、书籍筛选和展示
- 使用 Cloudflare Workers部署网站

---

📖 阅读入口

项目正在逐步为书库中的作品补充可靠的阅读、听书、购买或图书馆等入口。

由于不同作品的版权状态、数字化程度和可获得渠道不同，并不是所有作品都一定存在免费的在线全文。

故本项目会优先提供合法、可靠的阅读渠道。

---

🧪 项目状态

这是一个由个人独立完成的个人项目，目前仍在持续完善。

书库仍可能存在：

- 作品遗漏
- 作者信息需要修正
- 国家 / 地区分类存在争议
- 体裁分类需要调整
- 不同译名或版本造成的信息差异

如果你发现错误，欢迎提出 Issue 或联系作者。

欢迎纠错，也欢迎补充那些没有被更多人看见的作品。
